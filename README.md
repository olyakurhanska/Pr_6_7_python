ПР №6-7 — Flask

Практична робота з реалізації маршрутизації, CRUD-операцій та REST API у Flask.

Реалізовано

маршрутизація GET та POST запитів;

динамічні URL-параметри;

робота з request.args та request.form;

контролери та валідація JSON;

фільтрація та сортування;

Cookies та Sessions;

CRUD для блогу;

REST API для студентів;

пагінація та фільтрація;

серіалізація даних;

пошук;

API Key авторизація;

обробка помилок;

логування HTTP-запитів.

Запуск

Встановити Flask:

pip install flask

Запустити потрібний файл:

python practical_06_task_1_1.py

Після запуску відкрити адресу, яка буде вказана в консолі.
